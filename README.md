 # Cricket-Performance-Analyzer-2
A Python project to analyze cricket player performance using NumPy and Pandas.
About the project 
Cricket performance Analyzer is a python project that analyzes cricket match performance using python, NumPy and Pandas.
Technologies Used
.Python
.NumPy 
.Pandas
Features
1. Displays cricket match details.
2. Calculated total runs.
3. Calculated average runs.
4. Finds the highest score.
5. Finds the lowest score.
6. counts 50+ score.
7. Finds the best-performing match.
8. Sorts player performance by runs.
How to Run
1. Install Python.
2. Install NumPy and Pandas: pip install numpy pandas
3. Run the program: python cricket_analyzer.py
Project Purpose
This project helps beginners understand Python programming and basic data analysis using NumPy and Pandas.
